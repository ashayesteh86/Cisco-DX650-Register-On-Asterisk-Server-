# Cisco DX 650 – Native SIP with Asterisk (XML Provisioning)

Author: **Alireza Shayesteh**

This repository demonstrates how **Cisco DX 650** can be registered
**directly to Asterisk** using **XML provisioning via TFTP** –
without CUCM and without Android SIP applications.

> ⚠️ This is NOT officially supported by Cisco.
> Works only on specific firmware versions.

---

## ✅ What works
- Native SIP stack (no Android app)
- XML provisioning (SEP<MAC>.cnf.xml)
- Direct SIP REGISTER to Asterisk
- Inbound / outbound calls
- RTP audio

## ❌ What does NOT work
- MPP firmware
- Most enterprise-locked firmwares
- Guaranteed compatibility on all DX 650 devices
